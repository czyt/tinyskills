# 应用商店审核规则

本文档整理懒猫应用商店的审核标准和社区激励规则。

---

## 社区激励规则（2026-10 改版：双轨制）

**新机制：不再按应用类型区分激励资格，只要上架成功均可参与。**

### 1. 应用激励与打赏（双轨制）

- **下载量达标激励**：应用（移植或原创）上架后，累计下载量突破 **100 次** → 官方直接发放 **100 元**现金激励（通过商店打赏方式执行）。
- **用户打赏通道**：所有优质应用上架和更新均可开启打赏；开发者持续获得用户直接打赏收益，上不封顶。

> 旧版按应用类型（图床/笔记/VPN 等）排除激励的清单**已取消**——不再限制特定应用类型。

### 2. 编写商店应用攻略

- **所有攻略教程类内容均不再发放官方奖励红包**（旧版 50 元/篇政策取消）。
- 但攻略依然重要：①复杂应用提供详尽攻略是**通过审核的必要前提**；②好攻略能提升下载量（助达 100 次激励）与打赏收益。
- 上架基本规范：真实有效（实际测试）、图文并茂（建议截图+商店链接）、场景明确（避免孤立按钮描述）。
- 开箱即用简单工具无需复杂攻略即可上架。

### 3. 小龙猫技能上架

- 审核严格，注重**质量和安全性**（防范 Skill 盗取用户数据）
- 无初始激励；审核通过后根据**下载量**给予激励候补

---

## 不能上架应用商店的应用类型

以下类型**严禁上架**：

- 色情
- 赌博
- 毒品相关
- 空投（airdrop）
- 破解软件
- 违反中国法律的任何内容

---

## 应用审核主观标准

| 场景 | 结果 |
|------|------|
| 与已有应用高度相似 | 一般拒绝，除非有显著创新 |
| 过于简单/无功能/UI 粗糙 | 拒绝 |
| 仅英文界面 | 一般拒绝（热门高质量项目可放宽） |
| 复杂应用无攻略 | 要求补充文档 |

## ⚠️ 强制要求

### 1. 密码类应用限制

需要用户名/密码但应用商店页面未提供凭据的应用**不能发布**。

### 2. 文件选择器拦截（应用商店强制）

**有上传/下载功能的应用必须接入懒猫网盘自动拦截文件选择器**，未接入无法上架。

详见 [file-picker-intercept.md](file-picker-intercept.md)

## 规则适用范围

商店审核、激励资格与社区 / 用户自用是不同问题。激励政策（含旧版红包与新版双轨制）不构成商店上架门槛，商店要求也不能直接当作自用限制。本文所依据的上游审核规则没有列出 Docker socket 专项禁令；不得推断为全面禁止，也不承诺能通过商店审核。社区 / 自用 socket 配置见 [architecture.md](architecture.md)。
